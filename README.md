# Scratchpad has moved

Scratchpad now lives in [Taanviir/my-herdr-plugins](https://github.com/Taanviir/my-herdr-plugins/tree/main/scratchpad),
with the other Herdr plugins. This repo is archived.

To switch an existing install:

```bash
herdr plugin uninstall taanviir.scratchpad
herdr plugin install Taanviir/my-herdr-plugins/scratchpad
```

Your settings, key bindings and saved state stay where they are.
